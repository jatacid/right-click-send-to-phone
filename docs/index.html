Right Click Send to Phone

A simple chrome extension that lets you select text and right click send to phone! From any webpage direct to your phone via Slack, Discord, or any custom webhook.

Download Chrome Extension

How it Works

1

Install

Add the extension to your Chrome browser from the Web Store.

2

Connect

Choose Slack, Discord, or Custom webhook in settings and connect your account.

3

Send

Right-click any text or number and select "Right Click Send to Phone".

Setup Guide

Option A: Slack (Recommended)

Perfect for teams and individuals who use Slack daily.

  1. Click the extension icon and open Options.
  2. Click Sign in with Slack.
  3. Authorize the app to send messages to yourself.
  4. Done!

Option B: Discord (Manual)

Great for power users who prefer Discord.

  1. Open Discord > Server Settings > Integrations.
  2. Create a New Webhook and copy the URL.
  3. Paste the URL into the extension settings.
  4. Done!

Option C: Custom Webhook

Use any webhook service that accepts JSON POST requests.

  1. Click the extension icon and select Custom.
  2. Enter your webhook URL (must accept "text" or "content" field).
  3. Save settings.
  4. Done!
